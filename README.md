# Cok Dilli Kurumsal Site (PHP)

Umman merkezli bir holding icin dort dilli (TR/EN/AR/FA) kurumsal site. Cerceve kullanilmadan, duz PHP ile yazildi.

## Ozellikler

- Dort dilli icerik ve Arapca/Farsca icin RTL duzen
- Faaliyet alanlari, haberler, baskan mesaji sayfalari
- Departman bazli e-posta yonlendirmeli iletisim formu
- Yonetim paneli: icerik, ayar ve e-posta yonlendirme yonetimi
- E-posta imzasi uretici arac

## Kullanilan teknolojiler

PHP 8 (cercevesiz) - MySQL - Bootstrap

## Bu depo hakkinda

Gercek bir musteri projesinin **portfolyo icin yayinlanmis** surumudur.
Canli alan adlari, iletisim bilgileri ve parolalar ornek degerlerle
degistirilmistir. Kod ve mimari oldugu gibidir; veri gercek degildir.

## Kurulum

1. `kurulum.sql` / `*.sql` dosyasini MySQL'e aktarin
2. `config.php` icindeki veritabani bilgilerini duzenleyin
3. Sanal sunucunun kok dizinini proje klasorune yonlendirin
